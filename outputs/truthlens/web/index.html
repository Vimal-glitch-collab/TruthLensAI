METHODOLOGY

Know the limits.

Every report separates observations from conclusions.

01

Computer vision

Image checks measure JPEG recompression differences and pixel detail. Video checks sample up to 24 frames uniformly. Compression, lighting, and ordinary editing can produce unusual measurements.

02

Machine learning

The included training tool fits a logistic classifier to labeled image examples. An optional ONNX adapter supports a compatible binary image detector. No validated trained weights are included. Configured image models also examine sampled video frames; this does not replace a temporal or face-specific detector.

03

Language analysis

A small English lexicon flags loaded language, attribution cues, links, and emphasis. This is a rule-based review, not a trained factual-verification system. Quotations and legitimate journalism can trigger its checks.

04

Data and provenance

Image bytes remain in memory during analysis. Video files are stored temporarily and removed afterward. Reports retain filenames, file hashes, measurements, and matched phrases in a local SQLite database. Delete reports from history when finished.
